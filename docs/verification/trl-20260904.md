## Reload and Limits

원본 기록은 학습 종료 후 새 process에서 adapter를 읽고 같은 질문의 응답을 확인했다고 보고합니다.
이는 adapter 재로딩 증거이며 optimizer resume나 전체 상태의 수치 동등성 증거가 아닙니다.
생성 비교는 질문 두 개, held-out 평가는 대화 15개이므로 일반적인 품질 향상이나 성능 우위로 해석하지 않습니다.
